# Sistema de Gestão de Transportes

Sistema web leve, intuitivo e responsivo para automação do controle de fretes, viagens, cálculos de comissões de motoristas e acompanhamento financeiro de transportadoras.

## 🚀 Tecnologias Utilizadas
- **HTML5**: Estrutura semântica e acessível.
- **Tailwind CSS**: Estilização corporativa moderna e responsiva.
- **JavaScript (ES6)**: Lógica de cálculos, filtros dinâmicos e persistência no navegador.

## 📦 Como rodar localmente
1. Abra o arquivo `index.html` em qualquer navegador web.

## 🌐 Publicação no GitHub Pages
1. Crie um repositório público no GitHub.
2. Faça o upload dos arquivos `index.html`, `style.css`, `script.js` e `README.md`.
3. Em **Settings > Pages**, selecione a branch `main` e salve.
4. Seu link público estará disponível em instantes!
